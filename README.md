# Instagram 追蹤整理助手 (IG Following Organizer)

純前端、零密碼、零爬蟲、100% 本機運作的 Instagram 追蹤名單整理工具。
支援 **電腦雙欄並排鍵盤流** 與 **手機漏斗滑卡模式**，並內建專案記憶檔（SSOT）架構。

## 核心特色

- **官方匯出直接匯入**：支援 Instagram 官方下載的 `.zip` 壓縮檔或 `.json`（`following.json`、`followers_*.json`），純瀏覽器本機解析，不需上傳任何資料。
- **互追比對與防誤刪**：自動比對互追關係，提供「互追一鍵保留」漏斗與「互追取消防呆確認」。
- **單一重用 IG 視窗**：點擊開啟 IG 個人頁面時固定覆蓋同一個視窗，電腦雙欄並排時不再開出幾十個分頁。
- **雙模式體驗**：
  - 電腦：鍵盤極速流（`1` 保留、`2` 靜音、`3` 考慮取消、`4` 稍後再看、`Space` 開啟 IG、`Z` 復原）。
  - 手機：Tinder 滑卡手勢 + 單手拇指操作區。
- **本機自動存檔 & 跨裝置接續**：使用 `IndexedDB` 自動保存進度，支援匯出/匯入 JSON 備份檔跨裝置接續，以及匯出 **CSV / Excel (.xls)** 決策報表。

## 快速開始

直接用瀏覽器開啟 `index.html` 即可使用（不需安裝 Node.js 或啟動後端）。
若想在手機使用，將本專案推送至 GitHub 並開啟 **GitHub Pages**，即可用網址開啟（所有 IG 名單仍 100% 留在本機瀏覽器）。
